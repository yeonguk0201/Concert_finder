# W17/W19 기기 통합 검증 · 10/10 계획

실제 작업 시작일: 2026-10-09 (KST). 이 문서의 대기 항목은 성공 기록이 아니다.

## 준비

- 배포 URL·커밋, 노트북 OS/브라우저 버전, 갤럭시 모델/OS/Chrome 버전, 아이폰 모델/iOS 버전·홈 화면 설치 여부를 기록한다.
- A 계정은 대상 밴드를 찜하고 일정을 저장한다. B 계정은 찜/저장이 없는 비대상으로 둔다. 각 기기의 알림 권한·동의·등록 상태를 확인한다.
- 시간 변경·취소·라인업 테스트는 분리된 테스트 프로젝트에서 수행한다. 공개 카탈로그에 가상 공연을 추가하거나 검증된 공식 일정을 임의로 바꾸지 않는다. 테스트 데이터는 샘플임을 표시한다.
- 계정 삭제는 삭제용 계정 C를 만들어 확인한다. 실제 사용 계정이나 관리자 계정을 삭제하지 않는다.
- 기기 시계는 자동 동기화하고 KST 또는 UTC를 일관되게 사용한다. 토큰·이메일·푸시 endpoint·암호화 키를 결과에 붙이지 않는다.

## 로컬 검증 기록 · 2026-10-09

- 계정 삭제 endpoint: 무인증·만료 토큰·계정 불일치·확인 누락·허용하지 않은 메서드 차단, 서버 오류의 비밀정보 미노출 확인.
- 전체 마이그레이션 적용 PostgreSQL 엔진: 계정 삭제 시 찜·일정·동의·기기·발송/시도·계정 신호·관리자 권한 삭제, 타 계정과 카탈로그 유지, 이전 JWT 식별자의 저장 재생성 차단 확인.
- 로컬 앱은 실제 공개 카탈로그를 읽기만 했다. 계정/공연/알림 원격 데이터를 변경하거나 실제 계정을 삭제하지 않았다.
- 320px·390px·1280px에서 문서 가로 넘침 없음, 표시된 조작 버튼/입력/선택/안내 펼치기 높이 44px 이상 확인. 320px 로그인·공연 상세, 390px 개인정보 안내, 데스크톱 화면을 시각 점검했다.
- 본문 건너뛰기의 main 포커스, 키보드 상세 열기·Shift+Tab의 dialog 내 포커스 유지, Escape 닫기와 원래 버튼 복귀, 키보드 안내 펼치기를 확인했다. 실제 휴대폰 키보드·화면 읽기 도구는 미검증이다.
- 개발 중 hook 추가의 HMR 오류가 이전 탭에 남아 있었으나, 최종 새 탭의 로그인 화면/공개 카탈로그 로딩에서 콘솔 오류·경고 없음 확인.
- Node 26개 + UI 46개 = 자동 검사 72개 통과. Windows 샌드박스에서 Vitest 임시 변환 파일 ENOENT가 발생해 샌드박스 밖 `npx vitest run --maxWorkers=1`로 전체 UI를 재실행했다. lint·build 통과, build의 500kB 초과 청크 경고는 남아 있다. 새 삭제 함수 Deno check 통과.
