# NOL 후보 파서 준비

`scripts/nol.mjs`는 명시적으로 선택한 NOL 상품 URL의 후보 파서다. 기존 수집 실행기·source policy·자동 공개·알림에는 연결하지 않았다. NOL 자동 수집·재사용 이용허가는 아직 확보되지 않았다. 모듈 추가나 robots 허용을 이용허가로 해석하지 않는다.

일반예매와 선예매의 명시적 절대 날짜·시각을 구분하고 같은 종류의 상충 시각은 검수로 남긴다. 상품 기간을 매일의 공연 회차로 확장하지 않으며 신원·장소·발표 시각을 추정하지 않는다. 휠체어석 전화예매 안내를 일반예매 시각으로 사용하지 않는다.

입력 URL은 `https://nol.yanolja.com/ticket/products/숫자`로 제한하고 robots 확인 실패·차단에는 중단한다. 실제 상품은 HTML 구조나 별도 공지 형식이 달라 파싱에 실패할 수 있다. 검증은 합성 fixture이며 실제 페이지 통합이나 운영 수집 완료를 뜻하지 않는다. 허가 및 신원·시각·개별 회차·중복/취소/변경 검증 후 기존 lease/검수 경로에 연결하는 작업은 별도다.
