# NOL 예매 시각 회귀 검증

파서와 Reissue/NOL 연결 준비는 PR #53의 구현을 사용한다. PR #55의 추가 범위는 `tests/nol.test.mjs`의 회귀 검증과 이 문서뿐이다. #53을 먼저 dev에 병합한 뒤 #55를 병합한다. #53 병합 전에는 dev 기준 diff에 선행 구현도 표시되지만 #53 대비 파서·수집기·migration 변경은 없다.

NOL 자동 수집·재사용 이용허가는 아직 확보되지 않았다. 기본 연결 설정은 빈 배열이며 Reissue/NOL의 수집·공개는 활성화하지 않는다. 모듈 추가나 robots 허용을 이용허가로 해석하지 않는다.

일반예매와 선예매의 명시적 절대 날짜·시각을 구분하고 같은 종류의 상충 시각은 검수로 남긴다. 상품 기간을 매일의 공연 회차로 확장하지 않으며 명시된 공연 일시만 회차로 파싱한다. 신원·장소·발표 시각을 추정하지 않는다. 추가 회귀 테스트는 휠체어석 전화예매 안내만으로 일반예매 시각이나 공연 회차가 생성되지 않는지 확인한다. 일반/선예매 fixture의 공연명은 허구로 표시하며 실제 요네즈 공연의 예매 근거가 아니다.

실제 상품은 HTML 구조나 별도 공지 형식이 달라 파싱에 실패할 수 있다. 회귀 검증은 합성 fixture이며 운영 수집·공개·발송 완료를 뜻하지 않는다. #53의 URL 검증·robots·고정 회차 파싱·기존 source lease 보호를 유지하고 허가 및 신원·시각·중복/취소/변경 검증을 우회하지 않는다. #55는 운영 DB·공개 정책·발송 경로를 변경하지 않는다.
