# 공연 사실정보 이용 범위 확인 요청 초안

**미발송 초안**이다. 실제 수신처는 주최사의 현재 공식 문의 경로에서 확인해야 하며 자동으로 이메일/문의폼을 제출하지 않는다. NOL 허가를 전체 출시 전제로 요구하는 문서가 아니다.

제목: concert-finder 공연·예매 사실정보 안내를 위한 이용 가능 범위/API 문의

안녕하세요. 공연 일정을 안내하는 concert-finder를 준비하고 있습니다.
요네즈 켄시 GHOST 한국 공연의 공식 공지 또는 제공 가능한 API/feed에서 아래 사실정보를 확인하고, 출처를 표시해 서비스에 안내할 수 있는 범위를 문의드립니다.

- 공연명·아티스트·공연장·회차별 날짜와 시작 시각
- 일반/선예매별 오픈 시각, 변경·연기·취소 여부
- 공식 공지로 연결되는 링크와 출처명
- 허용되는 자동 확인 방식·주기, 저장 가능 기간 및 갱신·삭제 조건
- 서비스의 운영 형태에 따른 상업/비상업 사용 조건

포스터·사진·본문 전재·좌석도 복제·티켓 판매 대행을 요청하는 것은 아닙니다. 공식 API/feed/배포용 보도자료의 이용 정책이 있다면 해당 안내를 부탁드립니다. 별도 허가가 필요하다면 담당 부서와 필요한 절차를 알려주시면 감사하겠습니다.

확인된 범위를 넘겨 수집·공개하지 않으며, 정정·삭제 요청을 반영할 수 있도록 준비하겠습니다.

## 회신에서 확인할 내용

허용 주체/출처/대상 정보/자동 접근 방식/공개·링크·저장 범위/유효기간/출처표시·정정 조건을 구분한다. 단순히 링크를 받았거나 공개 페이지라는 이유로 전체 허가로 기록하지 않는다. 기존 허가나 공개 라이선스/API 조건으로 확인 가능한 경우 같은 서면 허가를 중복 요청할 필요는 없다.

## 어디에 문의하는가 / 별도 서면허가가 항상 필요한가

- **NOL을 제외한 현재 출시를 위해 이 초안을 NOL에 보낼 필요는 없다.** NOL 자체 자료를 이용하려는 별도 단계에서만 그 이용 주체에 문의한다.
- Live Nation 원문을 지속적으로 추출·재사용하려면 그 자료를 제공하는 Live Nation 측에 해당 이용 범위를 확인한다. 한국 사이트 약관과 본사 보도자료 호스트의 조건을 같은 것으로 자동 간주하지 않는다.
- KOPIS 등의 공식 API에 실제 적용되는 공개 이용조건/데이터 라이선스가 목적을 허용하고 필요한 서비스키/운영 승인·출처표시 조건을 충족한다면, 모든 주최사에 같은 서면허가를 따로 받을 필요가 있다는 뜻은 아니다. 공연상세API와 예매통계API·사진/포스터의 조건을 구분한다.
- 문의가 필요한 곳마다 미리 일괄 발송하지 않는다. 먼저 사용할 출처/정보/접근·저장·공개 방법과 기존 이용조건을 확인하고, 확인되지 않은 범위만 문의한다. 사실정보의 확인·출처링크와 원문·이미지 전재도 구분한다.
