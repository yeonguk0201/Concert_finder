# 10/11 공식 출처·아티스트·포스터 작업 기록

기준: 2026-10-11 KST. **로컬 구현과 실제 원문 조회를 완료했으며 원격 마이그레이션·업로드·운영 배포는 아직 하지 않았다. W21 전체 완료나 외부 테스트 준비 완료를 뜻하지 않는다.**

## 구현

- `scripts/collect-catalog.mjs`: ualive, Mint Paper, RADWIMPS를 독립 실행하고 실패를 출처별로 기록한다. 기본은 읽기 전용이며 `--upload` 때만 서버 RPC를 호출한다.
- 국내 5팀·일본 2팀·해외 1팀의 검토한 신원 목록을 이름·별칭·국적·장르 근거 URL과 함께 관리한다. MPMG 소개의 SORAN·THORNAPPLE·SURL·TOUCHED·YdBB, ONE OK ROCK 공식 ABOUT, RADWIMPS BIO, MCR 주최사 소개가 근거다. 신원 목록은 자동 장르 추론 모델이 아니다.
- RPC는 서버 역할/관리자에게만 허용된다. 기존 이름·별칭·국적뿐 아니라 공식 근거가 일치할 때 ID를 재사용하고 찜을 유지한다. 같은 이름이 여러 개거나 근거가 없으면 등록/연결을 보류한다. 새 신원은 밴드와 후보 연결을 같은 트랜잭션에서 저장한다. 공연이 없어도 밴드 목록에서 검색·찜할 수 있다.
- 혼합 페스티벌은 공식 라인업의 대상 아티스트 프로필 ID만 매칭한다. 다른 출연자와 출연일을 추정하지 않는다. RADWIMPS는 한국 언급과 밴드 이름이 있는 본문만 검수 후보로 보존하며, 멤버 솔로/일본 공연을 밴드의 한국 공연으로 넣지 않는다.
- 후보는 `review`, 초기 채움은 `initial_import=true`로 전달한다. 자동 공개·매시간 실행은 10/12 W26/W27 범위다. 기존 6시간 workflow는 변경하지 않았다.
- 홈의 최신 목록에 국내 공연·페스티벌도 포함하고 기존 분류/지역/정렬을 유지했다.
- 공연 이미지의 URL·원문·선택 근거·HEAD 확인 시각·MIME·크기를 수집한다. ualive는 공연 제목과 정확히 같은 대체 텍스트의 본문 이미지, Mint Paper는 해당 Festival ID의 `coverImage`만 사용한다. 로고·다른 아티스트 이미지는 선택하지 않는다. OG 이미지 추측은 지원하지 않는다.
- HTTPS 고정 이미지 호스트·JPEG/PNG/WebP만 허용한다. HEAD는 리다이렉트를 거부하고 10초 제한과 8MB 상한을 적용한다. 크기/형식 미확인·실패는 표시 후보에서 제외하되 검사 근거를 후보에 보존한다. 이미지를 다운로드하거나 재호스팅하지 않는다. HTML은 UTF-8 스트림으로 최대 2MB까지만 읽는다.
- 이미지 이용 조건과 공연 매칭을 확인한 관리자만 표시를 승인한다. 카드/상세는 원본 비율을 유지하고 공연명 대체 텍스트를 제공한다. 누락·로드 실패는 타이포 썸네일로 돌아간다. 이미지 변경은 새 공연/알림을 만들지 않고 변경 이력을 남긴다.

## 이미지 이용 조건

[Mint Paper 이용약관](https://www.mintpaper.co.kr/terms) 제8·9조의 무단 이용·지적재산권 제한을 확인했다. 외부 포스터 표시를 허용한다는 근거는 확보하지 못했으며 기본 `display_approved=false`다. ualive도 공개 이미지 URL 응답만으로 재사용 허락을 추정하지 않았다. 확인 전에는 앱에 타이포 썸네일을 표시하고 관리자에게 원문 링크를 제공한다. 출처별 표시 조건 확보가 W21의 남은 항목이다.

## 적용 순서와 검증

1. 기존 10/9까지의 마이그레이션 뒤에 `202610110001_catalog_expansion.sql`, `202610110002_concert_artwork.sql`을 순서대로 적용한다. 새 프런트는 `artwork` 열을 조회하므로 **DB 적용이 프런트 배포보다 먼저**다.
2. `node scripts/collect-catalog.mjs --output=collection-report.local`로 읽기 전용 결과를 확인한다. `--source=ualive|mintpaper|radwimps`로 한 출처만 실행할 수 있다. 보고서는 `*.local`로 보관하고 비밀값을 포함하지 않는다.
3. 서버의 `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` 설정 후 같은 명령에 `--upload`를 추가한다. 기존 ualive 전용 명령은 이전 RPC 경로이므로 새 다중 출처/신원 매칭에는 이 명령을 사용한다. 브라우저/VITE에 서비스 키를 넣지 않는다.
4. 후보의 밴드·발표일·회차를 대조하고 관리자 검수 입력으로 넘긴다. 원문 URL이 같은 기존 공연은 기존 ID·발표 정보·라인업·예매 ID를 유지한다. 이미 승인한 같은 이미지의 승인은 유지하고 URL 변경은 재검토한다. 기존 중요 변경을 자동 덮어쓰지 않는다.
5. 원격 공개·두 브라우저 반영·초기 무알림·포스터 표시 조건을 검증한다. 실패하면 새 수집을 멈추고 이전 프런트를 유지한다. 후보와 이력을 삭제해서 롤백하지 않는다.

검증: 전체 회귀에서 Node 33개·UI 53개 통과. 포스터 마이그레이션을 포함한 후속 수집/알림 DB 검사 16개와 관리자·홈·포스터·수집 UI 18개도 통과했다(기존 전체 검사와 중복). lint·build·diff 검사 통과. Windows 샌드박스 Vitest ENOENT는 권한 확장 재실행으로 해결했다. 기존 500kB 초과 빌드 청크 경고는 남아 있다.

로컬 브라우저 1280px·390px·320px에서 MCR 실제 포스터 전체와 원본 비율, 가로 2:1 테스트 이미지, 긴 제목, 이미지 없음/404 대체 및 가로 넘침 없음을 확인했다. 가로 이미지는 레이아웃 전용 합성 테스트이며 공식 포스터 확보로 집계하지 않는다. 표시 승인 미완료 포스터를 운영에 공개하지 않았다. 실제 운영 프런트와 마이그레이션 연결, 상세의 원격 이미지/재연결은 후속 검증이다.

남은 일: 원격 적용·업로드·배포, 일본 예정 한국 공연 확보와 지원 아티스트 확대, 출처별 이미지 표시 조건 확인, 운영 데이터 정정/공개 중단, 10/12 매시간 실행·조건부 자동 공개와 24시간 관측. 데이터 준비 기준 통과 전 W18 외부 테스트를 시작하지 않는다.
