# 승인 시안의 실제 서비스 적용

`public/ui-concepts/`와 오프라인 시안은 수정하지 않는다. `preview.css`와 `flow.css`를 `src/design/approved-preview.css`, `src/design/approved-flow.css`에 원문 그대로 복사하고, 실제 React 화면의 DOM 구조와 클래스도 승인 시안에 맞춘다. 기존 사이드바와 그 위에 덧씌운 스타일은 실제 앱에서 불러오지 않는다. `ServiceDesign.css`에는 실제 사진 출처, 공식 포스터, 계정·관리자 기능 등 데이터 연결에 필요한 스타일만 둔다.

- 공연 둘러보기에는 공연만 표시한다. 검색 결과는 전체·아티스트·공연으로 나눈다.
- 아티스트 사진과 이름에서 `?page=artist&artist=<id>`로 이동한다. 소개는 확인된 이름·분류·별칭과 공식 링크만 사용한다. 별도 공식 소개 데이터가 없는 상태에서 시안의 소개를 실제 약력처럼 사용하지 않는다.
- 실리카겔의 확인된 영상은 MusicBrainz ID로 연결한다. 다른 아티스트는 빈 목록과 YouTube 검색 링크를 제공한다. 영상 목록을 이름만으로 매칭하거나 임의 채널을 공식 계정으로 지정하지 않는다. 영상 출처는 [시안 기록](ui-concepts-20261020.md)의 공식 영상 링크와 같다.
- 영상은 두 카드씩 이동하며 마우스 드래그·터치 스크롤·키보드 방향키를 지원한다. 썸네일 로딩 실패 시 대체 이미지를 표시한다.
- 일정은 한국 시간의 티켓 오픈 날짜로 필터링한다. 저장 일정이 없으면 선택 날짜에 열리는 공연을 최대 세 개 추천한다. 여러 날의 페스티벌은 기간 전체를 포함하고 취소·공개 중단 공연은 추천에서 제외한다. 전체 보기에서는 미정·공개 중단 저장 일정도 삭제할 수 있다.
- 로그인, 외부 아티스트 검색·등록, 계정 동기화, 일정 저장, ICS 다운로드, 알림 설정, 관리자 권한과 검수 기능은 기존 구현을 사용한다. 사진의 출처·라이선스·YouTube 사진 만료 처리를 유지한다.
- 로그인은 시안의 모달 구조로 구현하고 실제 `useAuth`의 이메일 발송·인증번호 확인에 연결한다. 공연 상세는 시안과 같은 전체 페이지 구조로 표시한다.
- 사용자 요청에 따라 베타 검증·테스트 공연 안내와 공연·계정의 상시 연결 상태 행을 제거한다. 초기 로딩은 화면 위치를 밀지 않고 보조기기에 알린다. 실패한 요청의 재시도와 공개 중단 안내는 필요한 상황에만 표시한다.

실제 API에 OTP를 요청하거나 계정 데이터를 변경하는 수동 검증은 하지 않는다. UI 통합 테스트와 시안 비교에는 계정 모드 모킹을 사용한다. 실제 설정으로 실행한 앱에서도 메인과 로그인 모달을 읽기 전용으로 확인한다. 이 변경은 배포를 포함하지 않는다.

## 검증

- `npm run lint`, `npm run build` 통과. 빌드에는 기존 단일 JS 번들의 500kB 초과 경고가 남아 있다.
- Node 로직·DB 테스트 111개, Vitest UI 테스트 99개 통과. Windows 샌드박스의 임시 파일 rename/워커 캐시 권한 문제로 전체 테스트는 일반 로컬 권한으로 실행했다.
- Edge 브라우저 1440·1042·390·320px에서 메인·공연 둘러보기·검색·아티스트 상세·공연 상세·로그인·일정을 확인했다. 수평 넘침 없음, 두 카드 이동, 소개 펼침, 브라우저 뒤로가기, 로그인 입력 노출을 확인했다.
- 썸네일을 불러올 수 없는 네트워크에서는 대체 상태를 확인했다. 모든 아티스트의 영상·공식 약력을 확보한 변경은 아니다.
- 시안 파일은 diff 없음. 원격 배포·푸시·PR 생성은 포함하지 않는다.
- 같은 데이터로 비교할 때 메인 14개 주요 요소의 위치와 크기가 네 가지 화면 폭에서 모두 1px 이내로 일치한다. 로그인·검색·아티스트·찜·일정의 제목과 카드·캘린더 배치도 비교했다. 목록 전체 높이는 실제 공연 개수에 따라 달라진다. 비교에서는 시안 전용 화면 이동 막대·가상 데이터 설명·체험 버튼을 제외했다.
- `tests/approved-design.test.mjs`가 시안과 실제 앱의 기준 CSS가 동일한지 검사한다.
