## 검증 및 한계

선정 40개 ID를 종료 후 DB에서 재조회했고 승인3팀의 새 상태/분류, 나머지37팀의 원래 상태 및 전체40팀 이름·별칭 보존을 확인했다. 결과 JSON을 UTF-8로 다시 파싱하고 git diff --check를 수행한다. 앱 코드 변경이 없어 앱 빌드/테스트를 새로 수행하지 않았다.

The Cult의 예전 출처는 비공식 사이트임을 확인하여 승인 근거로 사용하지 않고 Beggars Banquet 본문으로 대체했다. Saga·The Cranberries도 접근 실패한 기존 자료 대신 새 공식 본문을 확보했다. 후보·검색 결과만으로 완료를 세지 않았다.

- 새 batch begin 전에 core plan을 생성하지 못했다. 활성 batch는 변경하지 않았으며 다음 경계용 core-plan.json을 준비했다.
- 로컬 입력 검증 중 확인되지 않은 예상 MBID와 context 불일치는 운영 신원 충돌 증거가 아니다. 해당 입력은 제출하지 않았다.
- 외부 ID 제공처 cooldown을 우회하지 않았다. 미완료 요건은 비대상/제외 판정이 아니다.
- 신규 identity CLI는 아직 없으며 새 등록·별칭을 별도 writer로 우회하지 않음. 기존 검수는 계속 수행.
- LASTFM_API_KEY는 이 환경에서 미관측; 인기 지표 조사 미실행.
- 기존 channel manifest 대상0건; 새 공식 링크/API 교차 검증과 사진 확보는 미완료.
- 37팀을 새 검수 완료로 세지 않음. 원래 연구 완료 시각/유효기간 보존.

다음 새 batch에서는 준비한 core-plan.json을 최신 snapshot으로 다시 생성하고 --priority-file로 전달한다. 이번 활성 선택은 변경하지 않았다. 4시간 주기는 Codex 앱이 관리하며 cooldown/서버 잠금은 유지한다. 전체 카탈로그/사진 확보는 미완료다.
